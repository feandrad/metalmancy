# Texture Report

This directory contains the missing textures report for the Metalmancy material system.

## Report Generation

The report is automatically generated by running:

```bash
gradle :common:generateTextureReport
```

This will scan all materials defined in `Materials.kt` and check which textures exist in the `common/src/main/resources/assets/metalmancy/textures` directory.

## Current Status

As of the last report generation:

- **Total missing textures:** 162
- **Materials with missing textures:** 28
- **Block textures missing:** 80
- **Item textures missing:** 82

## Using the Report

The `missing_textures_report.md` file contains:

1. **Summary** - Overview of missing textures
2. **Missing Textures by Material** - Organized by material name with checkboxes
3. **Missing Textures by Type** - Organized by block/item type
4. **Full List** - Copy-paste friendly list of all missing texture paths

## Creating Textures

When creating textures, place them in:

- Block textures: `common/src/main/resources/assets/metalmancy/textures/block/`
- Item textures: `common/src/main/resources/assets/metalmancy/textures/item/`

After creating textures, regenerate the report to update the missing list.

## Texture Naming Convention

Textures follow the pattern: `{material_name}_{part}.png`

Examples:
- `zinc_ore.png` - Zinc ore block
- `zinc_deepslate_ore.png` - Zinc deepslate ore block
- `zinc_ingot.png` - Zinc ingot item
- `zinc_nugget.png` - Zinc nugget item
- `ruby_gem.png` - Ruby gem item

## Regenerating the Report

To regenerate the report after adding textures:

```bash
gradle :common:generateTextureReport
```

The report will be updated with the current status of missing textures.
